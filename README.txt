Create an instance of the class and print out the result of calling each method. Each method returns a string so it should easily be printable.

For example:
9 + 1 = System.out.println(strMath.StrAdd("9", "1"));
99 + 9999 = System.out.println(strMath.StrMult("99", "9999"));
100! = System.out.println(strMath.StrFact("1000"));

Compile and run the file using javac and java.
